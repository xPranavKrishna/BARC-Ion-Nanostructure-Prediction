# Predictive Modeling of Ion-Induced Nanostructure Formation

Machine learning project developed during my internship at **Bhabha Atomic Research Centre (BARC), Visakhapatnam**.

The project focuses on predicting ion-induced nanostructure formation on material surfaces using experimental parameters such as ion, energy, incidence angle, fluence, and temperature.

## Machine Learning

- Logistic Regression
- Random Forest
- SVC
- XGBoost
- SMOTE
- GridSearchCV

The optimized Random Forest model achieved approximately **79% accuracy** on the test dataset.
